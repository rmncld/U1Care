# 0.6.0

Front-facing docking support inspired by the supplied machine reference, with live filament colors and a plain mounted label. No table, cyan marker or mount outline. RFID priority, labeled job fallback and unknown-data handling follow U1Deck. Maintenance records and Hub dashboards are unchanged. [Release details](docs/RELEASE-0.6.0.md).

# 0.5.0

Offer reconnection when a printer entry remains after HACS removal, preserving its records and entities. Add a native four-toolhead card with local U1Deck vector illustrations, individual changes and total. [Release details](docs/RELEASE-0.5.0.md).

# 0.4.2

Restore the dashboard logo alongside the custom printer name. Repair only the exact default banner, with a backup; retain customized headers, dates and service records. Document HACS update detection and its custom-repository polling interval. [Release details](docs/RELEASE-0.4.2.md).

# 0.4.1

Pogo contacts now display both remaining days and remaining changes, including unknown or overdue values. Existing dashboards update through the sensor state; no storage or dashboard migration. Dates and maintenance events are preserved. [Release details](docs/RELEASE-0.4.1.md).

# 0.4.0

Four real toolhead counters from U1Deck, persistent cumulative pogo tracking, custom printer name and commissioning date at setup, no new demo entries. Non-destructive v0.3.6 migration, preserved entities/events and incremental dashboard update. [Release details](docs/RELEASE-0.4.0.md).
